# F4: Edit free-mode survey semantics

Use this scene to change the survey title or description, edit question text or options, delete or reorder questions, or combine edits with additions.

1. Read both `question_schema_generate.json` and `survey-unified-generate.html`.
2. Apply every semantic change to both artifact sources. Never update only JSON or only HTML.
3. In JSON, update survey metadata and question fields, remove deleted entries, and normalize `sort` in increments of 1000.
4. In HTML, synchronize `<title>`, visible metadata, question titles, option text and values, question numbers, indexes, and DOM order. `data-title` excludes the visible number.
5. For deletion, remove the complete generated question region plus its `buildAnswers()` and base-event entries. For `GENERIC`, synchronize schema fields and the actual generic-container implementation.
6. Preserve the bridge script, survey and question identity attributes, `buildAnswers()`, `submitSurvey()`, answer state, base bindings, and custom CSS/JS region markers.
7. Recheck type-specific styles, submission visibility, custom page totals, and all HTML/CSS/JS selectors.
8. Validate:

   ```bash
   node --check <survey-workspace>/survey-ui.js
   python survey-create/scripts/validate_free_mode_survey.py --schema <survey-workspace>/question_schema_generate.json --html <survey-workspace>/survey-unified-generate.html --dir <survey-workspace>
   ```

Use `generate_free_mode_skeleton.py --force` only for a badly damaged survey or an intentional complete refresh. Preserve custom regions first, then repeat all F1 finishing steps.
