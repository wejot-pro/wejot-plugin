# S1: Create or fully refresh a standard survey

Use this scene for a new standard-mode survey whose author accepts the default layout, or when the complete question area must be regenerated. For custom layout, interaction, or DOM, use F1 instead.

## Workflow

1. Read `../minimal_survey_spec.json`. Read `../minimal_survey_spec.example.json` only for structure; never copy its topic, copy, or UUIDs.
2. If the requirements include branching, visibility, derived answers, dynamic candidates, exclusivity, or termination, use `survey-logic` and maintain a durable TODO of trigger, condition, action, and acceptance criteria.
3. Create `survey_spec.json` with one `questions` array. Preserve every type, option or row, required flag, choice bound, scale range, and page break from the source requirements.
4. For a `BOUNDED_STANDARD` dynamic radio, checkbox, or matrix target, declare the complete canonical option or row catalog in the spec. Runtime `value` or unique `schemaLabel` must map back to that catalog. Add `dynamicRows: true` for a dynamic standard matrix.
5. For `GENERIC`, include `answerKeys`, `genericStyle`, `genericHtml`, `genericScript`, `userAnswersSample`, and `chartHtml`, and follow the relevant `survey-components` rule.
6. Generate artifacts:

   ```bash
   python generate_standard_survey.py --spec <survey-workspace>/survey_spec.json --output-dir <survey-workspace> --locale <respondent-locale>
   ```

7. Implement every logic TODO through `survey-logic`. Edit only the business-logic extension region of `survey-ui.js`; do not overwrite the infrastructure or remove `window.SurveyRuntime`.
8. Check every `setQuestionItems()` and `setLogicAnswer()` result. On failure, log the structured result and stop the dependent visibility, derivation, or submission chain. After installing non-empty candidates, verify their exposure, count, slot, and identities.
9. Never simulate dynamic candidates by hiding catalog items with CSS. Keep random assignment stable within one response, clear invalid downstream paths, and clear an old derived value once when a hidden derived question returns to manual input.
10. If a header image is used, keep submission metadata and the HTML `.header-img` URL identical.
11. Validate:

   ```bash
   python validate_standard_survey.py --dir <survey-workspace>
   ```

Only submit artifacts when the user explicitly requests submission.

The standard runtime stores answers and the current page in `localStorage` by default. The bundled template sets `SURVEY_LOCAL_DRAFT_DEFAULT = true`; set it to `false` to disable this same-device behavior. Do not describe it as cross-device draft support or replace it with a second custom draft system.
