# Questionnaire Module Templates

Use these as blueprint starting points, not mandatory forms. Each selected module must map to a confirmed objective.

## Common primitives

- Screening and eligibility
- Category context, behavior, and recall
- Awareness, consideration, trial, or usage
- Attitudes, evaluation, satisfaction, or effort
- Needs, barriers, motivations, and trade-offs
- Outcome, intent, recommendation, or retention
- Sensitive and demographic profile

## U&A

Screening -> category behavior -> awareness and usage -> attitudes and needs -> barriers and unmet needs -> intent -> profile.

## NPS, CSAT, or CES

Eligibility/context -> overall measure -> diagnostic dimensions -> open reason -> recovery or improvement priority -> profile. Keep the headline score separate from its diagnostic items.

## Brand health

Category eligibility -> unaided awareness -> aided awareness -> familiarity -> consideration or usage -> imagery and associations -> preference or intent -> profile. Avoid exposing later brand lists before unaided recall.

## Concept or price test

Eligibility -> baseline behavior -> randomized or controlled concept exposure -> comprehension -> appeal and relevance -> strengths and concerns -> purchase intent -> price measure -> comparison or preference -> profile. Preserve exposure identity and order when randomization matters.

## General study

Screening -> current context -> core constructs -> diagnostic follow-up -> open evidence -> outcome or intent -> profile.

## Blueprint checks

- State each module's purpose, estimated question count, and mapped objectives.
- Estimate duration from actual task burden, not question count alone.
- Put cognitively easy, non-sensitive content early unless screening or experimental control requires another order.
- Keep sensitive and profile items late.
- Do not add a stock module that does not change a decision.
