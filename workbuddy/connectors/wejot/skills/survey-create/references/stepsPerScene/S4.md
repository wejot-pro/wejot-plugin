# S4: Customize outside the standard question region

Use this scene to add standard-mode decorations, header extensions, or footer explanations that are not questions.

- Place custom DOM before `<!-- QUESTION_LIST_START` or after `<!-- QUESTION_INSERT_POINT -->`.
- Alternatively, use a `GENERIC` question for reversible, schema-owned content.
- DOM placed inside the generated question region but absent from the spec is discarded the next time a generator rewrites that region.
