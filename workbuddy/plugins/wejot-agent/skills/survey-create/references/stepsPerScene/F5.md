# F5: Free-mode DOM outside the question region

Use this scene for decorations, header extensions, footer explanations, in-survey endings, and other DOM that is not represented by a question spec.

- Place durable custom DOM before `<!-- QUESTION_LIST_START` or after `<!-- QUESTION_INSERT_POINT -->`, or model reversible content as a `GENERIC` question.
- Generated and append scripts discard non-spec DOM placed inside the generated question region.
- Preserve custom blocks before a `--force` regeneration and restore them outside the question list afterward.
- Do not cover the survey's submission entry point.
- If generation or append runs afterward, recheck type-specific CSS, visible submission, and HTML/CSS/JS selector closure.
- Validate `survey-ui.js` after changing it.
- For an ending that persists answers without leaving the survey, read `../submit-stay-pattern.md`, render the ending, and use `submitAndStay`. Place the ending outside the generated question list.
