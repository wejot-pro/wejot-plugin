# S2: Append questions to a standard survey

Use this scene when standard-mode artifacts already exist and the task only appends questions at the end, before a named comment anchor, or at the end of a specific page.

1. Create `append_spec.json` using `../minimal_survey_spec.json`; its `questions` array contains only new questions.
2. Append at the survey end:

   ```bash
   python survey-create/scripts/append_questions_to_survey.py --spec <survey-workspace>/append_spec.json --target-dir <survey-workspace> --locale <respondent-locale>
   ```

3. To insert before an explicit marker, first add a comment such as `<!-- AGENT_ANCHOR_A7K2M9Q4 -->`, then pass `--anchor-comment AGENT_ANCHOR_A7K2M9Q4`.
4. To insert at the end of page N, pass `--insert-page-end N` and give every appended question `page: N`.
5. Validate:

   ```bash
   python survey-create/scripts/validate_standard_survey.py --dir <survey-workspace>
   ```

Default end insertion aligns new HTML `data-page` values with the final DOM page. Page truth lives in HTML; `question_schema_generate.json` has no `page` field. Anchor and page insertion also reindex questions, visible numbers, schema `sort`, and generated `survey-ui.js` constants.
