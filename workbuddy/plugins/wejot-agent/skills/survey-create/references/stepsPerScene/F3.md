# F3: Append questions to a free-mode survey

Use this scene when free-mode artifacts already exist and only new questions are appended. Do not use it to edit existing question semantics or order.

1. Create `append_spec.json` from `../minimal_survey_spec.json`, containing only new questions.
2. Append without replacing the HTML file:

   ```bash
   python survey-create/scripts/append_questions_to_free_mode_survey.py --spec <survey-workspace>/append_spec.json --target-dir <survey-workspace> --locale <respondent-locale>
   ```

3. Use `--anchor-comment AGENT_ANCHOR_XXXXXXXX` for an explicit comment marker, or `--insert-page-end N` with matching `page` values.
4. Complete any new generic container manually; the skeleton does not expand generic source fields.
5. Add styles for all present question types, especially new scale and matrix controls. Confirm a visible submission action and update any custom `totalPages` count.
6. Verify HTML/CSS/JS selectors, startup visibility, navigation, and submission. Validation cannot replace this runtime check.

The append script preserves custom CSS/JS regions, updates schema, DOM, `buildAnswers()`, and base events, and invokes free-mode validation. A zero-error validation removes temporary `*spec.json` drafts.
