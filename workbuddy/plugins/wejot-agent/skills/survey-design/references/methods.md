# Survey Design Method Summary

Use this file as a cross-stage reminder. The focused references contain the operational checks for each stage.

## Total survey error

Consider coverage, sampling, nonresponse, measurement, processing, and reporting error. Record material risks and identify whether wording, sampling, fieldwork, data processing, or later analysis controls each risk.

## Construct operationalization

For each objective, record `objective -> construct -> dimension -> indicator -> item`. An indicator must be observable through the proposed respondent task and have a defined response scale or coding rule.

## Cognitive burden

Check comprehension, retrieval, judgment, and response mapping. Specify recall windows, define unfamiliar terms, avoid assumptions of knowledge, and offer an unknown or not-applicable path where warranted.

## Order and modules

Use a coherent flow from eligibility and concrete context toward evaluation, sensitive items, and profile questions. Explain exceptions rather than silently rearranging the order.

## Confirmation gate

Keep drafts visibly unconfirmed. The final brief must include the research question, objectives and stopping conditions, audience and exclusions, construct map, module blueprint, item drafts, duration, unresolved risks, and intended production skill. Generation starts only after explicit user confirmation.
