# S3: Rewrite, delete, or reorder standard questions

Use this scene for standard-mode title or description changes, question edits, deletion, reordering, or mixed semantic changes.

1. Rebuild an editable draft from current artifacts:

   ```bash
   python survey-create/scripts/rebuild_spec_from_schema.py --workdir <survey-workspace> --locale <respondent-locale>
   ```

2. Edit `survey_spec.json`, keeping question order and `page` values coherent.
3. Regenerate and validate:

   ```bash
   python survey-create/scripts/generate_standard_survey.py --spec <survey-workspace>/survey_spec.json --locale <respondent-locale>
   python survey-create/scripts/validate_standard_survey.py --dir <survey-workspace>
   ```

4. The generator refreshes auto-generated `Qn_UUID` and `Qn_OPT_n` constants. Do not edit that generated region.
5. Audit the business-logic extension region in `survey-ui.js`. If logic refers to removed or reordered questions, update it to the new schema and HTML UUIDs. Prefer generated `Qn_UUID` values over hard-coded hexadecimal UUIDs.

The standard runtime stores answers and the current page in `localStorage` by default. The bundled template sets `SURVEY_LOCAL_DRAFT_DEFAULT = true`; set it to `false` to disable this same-device behavior. Do not add a duplicate draft implementation or describe it as cross-device support.
