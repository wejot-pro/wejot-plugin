# Survey Design Methodology Framework

Use this reference when converting a confirmed research question into measurable survey content.

## Total survey error

Review coverage, sampling, nonresponse, measurement, processing, and reporting error. A questionnaire mainly controls measurement and part of nonresponse; do not imply that good wording fixes a weak sample or unsupported causal design.

## Construct operationalization

Map `research question -> objective -> construct -> dimension -> indicator -> item`.

- A construct is the concept to be measured.
- A dimension is a meaningful aspect of that construct.
- An indicator is an observable response that provides evidence about the dimension.
- An item is the respondent task used to collect that evidence.

Every objective needs at least one defensible indicator. Every item must map back to an indicator. Remove orphan items and challenge objectives that cannot be measured through the available method.

## Respondent cognition

For each item, check four stages:

1. Comprehension: terms, subject, and requested judgment are clear.
2. Retrieval: the respondent can recall or access the requested information.
3. Judgment: the question does not lead, shame, presume, or combine separate constructs.
4. Response: the available controls accurately express the respondent's answer.

## Question order

Prefer a funnel: screening and eligibility, concrete behavior or context, awareness and evaluation, outcomes or intent, sensitive questions, then demographics. Group related items, avoid context effects where possible, and explain deviations.

## Market-research modules

Common modules include screening, category behavior, awareness and usage, attitudes or satisfaction, needs and barriers, concept or price evaluation, intent, and profile. Select only modules needed to answer confirmed objectives.
